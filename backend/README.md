### If you wish to test the backend on its own, you can follow the steps below:

# Prerequesites

- [uv](https://github.com/astral-sh/uv)

<br />

# Running

1. Open terminal in `backend`
2. Run `uv sync`
3. Start the server with `uv run python manage.py runserver`

<br />

The local development server will be available at: `http://localhost:8000`

- The admin panel can be accessed at: `http://localhost:8000/admin/`
- Endpoint documentation (generated by Ninja) is available at: `http://localhost:8000/api/docs`
