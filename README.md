# Prerequisites

* [Docker](https://www.docker.com/) and Docker Desktop installed.

<br/>

# Installation

If you wish to run this project locally for development or review, it is fully containerized with Docker.

1.  Clone the repo
    ```sh
    git clone https://github.com/forthfora/evp-website
    ```
2.  Navigate to the directory
    ```sh
    cd evp-website
    ```
3.  Build and spin up the containers (ensure Docker Desktop is running)
    ```sh
    docker compose up --build
    ```

The local development server will be available at: `http://localhost:16016`
* The admin panel can be accessed at: `http://localhost:16016/admin/`
* Endpoint documentation (generated by Ninja) is available at: `http://localhost:16016/api/docs`
